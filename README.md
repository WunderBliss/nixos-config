# nixos-config

Owen's NixOS — Hyprland + DankMaterialShell on a single-host flake.

## Host

`nixos` — AMD desktop, ultrawide 5120×1440@144Hz 10-bit HDR on DP-1. Single user (`owen`). Fish shell.

## Stack

- **Compositor:** Hyprland with [Hyprspace](https://github.com/KZDKM/Hyprspace) overview
- **Shell/bar:** [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell) with matugen wallpaper-based theming
- **Launcher:** [walker](https://github.com/abenz1267/walker) / elephant
- **Terminal:** Ghostty (theme auto-generated by DMS)
- **Editor:** NixVim (declarative Neovim — see `nixvim.nix`)
- **Browser:** Zen Browser (via flake)
- **File manager:** yazi (also wired into xdg-desktop-portal-termfilechooser)
- **Gaming:** Steam + gamescope + mangohud; Star Citizen via nix-citizen

## Layout

```
flake.nix                   inputs + outputs (NixOS + home-manager wired together)
configuration.nix           system: boot, networking, services, hardware-adjacent
home.nix                    home-manager: per-user programs and config
nixvim.nix                  Neovim config (imported by home.nix)
hardware-configuration.nix  auto-generated (do not hand-edit)
modules/                    package lists + future split modules
```

See [`CLAUDE.md`](./CLAUDE.md) for a deeper architecture tour intended for Claude Code.

## Commands

Fish aliases defined in `home.nix`:

```fish
rebuild   # sudo nixos-rebuild switch --flake .#nixos
update    # nix flake update
```

Or expanded:

```bash
sudo nixos-rebuild switch --flake /home/owen/.dotfiles#nixos
nix flake update /home/owen/.dotfiles
```

After a rebuild, `nvd diff /run/current-system /nix/var/nix/profiles/system` shows exactly what changed.

## Formatter

```bash
nix fmt        # formats every .nix file in the repo (nixfmt-rfc-style)
```

## Local checks (optional)

Install a pre-commit hook that runs `nix fmt --check` and `nix flake check` on every commit:

```bash
./scripts/install-hooks.sh
```

The same checks run in CI on every PR ([`.github/workflows/check.yml`](./.github/workflows/check.yml)).
